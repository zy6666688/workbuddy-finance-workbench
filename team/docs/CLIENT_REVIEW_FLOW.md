# 客户建档到复核交付

## 日常操作路径

1. 负责人在客户公司建立档案，填写内部编号、服务交接备注、默认经办、默认复核和每月资料要求，可同时创建首月任务。
2. 保存共同完成档案、所选人员授权和首月任务；任何一项失败整体撤回。重复客户编号提示冲突，不创建第二家公司。
3. 从档案进入本月资料收集。缺件可直接上传并关联，也可关联已有原件、复制补件清单或由独立复核人说明理由豁免。
4. 经办处理和 WorkBuddy 回传完成后，先检查送审条件，再提交校验说明和具体成果版本。
5. 审核中心按“我可复核、全部待复核、退回跟进、待交付、重开申请”组织事项；退回必须说明原因，重新送审形成新版本。
6. 通过后人工完成客户交付，上传证据并登记；归档后更正须申请独立重开，保留旧记录。

## 人员交接与隔离

- 默认分工和模板只影响新建月份；已有月份到“分工与记录”明确调整。
- 修改默认分工会为所选两人授予公司访问，不自动撤销旧协作人员，也不自动重写历史月份。
- 撤销访问立即生效；界面提示默认分工待完善。账号停用、角色变化和历史经办参与情况同样影响送审资格。
- 工作单的可选接手人员来自本公司授权的在职员工。历史经办者不能被重新分配为本批次复核人。
- 客户列表、详情、统计、审核队列均使用登录身份和数据库行级权限；没有管理员统计通道绕过机构或公司边界。

## 升级与范围

第 008 号迁移增加客户交接资料、默认经办和复核字段，不修改已有公司授权、月度分工或资料清单。旧公司默认分工留空，由负责人确认后配置。联系人及备注存储在私有数据库，公开源代码和示例不包含真实客户资料。

客户档案展示最近 24 个月份，更早月份可在月度交付中切换期间查看。队列按当前期间和公司范围筛选，不跨期间自动合并。系统不自动发送催收、批量批准成果或替代人工财税判断。

验证范围和浏览器文件选择限制见 [验收记录](ACCEPTANCE.md)，具体操作见 [操作手册](USER_GUIDE.md)。
