# 团队交付工作台：参考与改进

## 参考项目

- [Accounting Practice for Claude Code](https://github.com/Enterprise-DNA-OS/accounting-practice-for-claude-code)：面向会计事务所的客户、期限、缺件、复核队列与工作量记录。采用其“先识别需要关注的工作”的组织方式。该项目主要由数据库和命令工作流组成，不能把它当作成熟中文代账网页产品。
- [Frappe Helpdesk 的任务管理](https://frappe.io/helpdesk/ticket-management)：列表呈现客户、状态、负责人和期限，并支持筛选与视图。参考其日常操作的信息密度，保留本项目独立复核和版本控制约束。
- [Bigcapital](https://github.com/bigcapitalhq/bigcapital)：开源会计与库存系统。用于区分“会计核算系统”和“代账交付管理”的范围，本轮没有复制其代码或引入自动记账功能。

本轮使用原创实现，参考上述信息组织方式，没有移植第三方源码、品牌或样式资源。

## 已落地

1. 月度交付首屏展示工作单、待补件、逾期、待复核、待交付及已归档数量。点击指标进入对应清单。
2. 列表显示客户编号、期间、阶段、必需资料进度、经办、复核、截止日期及下一步。列表与阶段看板可切换。
3. 支持我经办、我复核、客户搜索、阶段、缺件、逾期、七天内到期与排序；统计从服务端按权限和筛选范围计算，不使用当前页数量代替总量。
4. 工作单分为资料收集、经办处理、复核与交付、分工与记录；顶部显示当前阶段及下一步，保留原有材料、附件、任务包、回传、审批、交付、重开及分工功能。
5. 新建月度工作只在主动打开时出现。批量安排要求明确勾选客户，不再默认为整个已加载列表。
6. 新列表、指标与动态沿用真实登录身份和数据库行级权限。搜索、统计不放宽跨客户或跨机构的访问。
7. 收集资料时可复制按公司、期间生成的补件清单，由经办核对后自行发送；系统不会自动联系客户。

## 口径与范围

- 所有统计限定于顶部公司与期间，再应用搜索和“全部／我经办／我复核”范围。阶段和关注事项进一步筛选工作清单。
- 待补件指收集阶段缺少至少一项必需资料的工作单；豁免计入已处理。其他阶段保留原材料状态。
- 逾期不包含已归档任务；未来七天到期包括今天与第七天，日期按上海时区判断。期限仍由团队配置。
- 看板按当前分页展示，底部标明本页和总量；不会拖动卡片绕过审批来改状态。
- 动态显示最近 50 条针对工作单的审计事件；附件完整索引和历史复核仍在各自区块。
- 没有新增客户自动催收消息、法定税期计算、任意流程设计器、自动记账或报税功能。
