## 容量测试

- 环境：Intel Core i7-14700F，Docker Linux x64，28 个可见逻辑 CPU，容器环境可见内存约 16GiB；Node 24.22.1，PostgreSQL 17.11。
- 单机构合成数据：100 个账号、2000 家公司、24000 份月度工作单、100000 条文件索引。
- 50 个独立服务端会话并发，经 Caddy → 应用 → PostgreSQL，共 200 次分页、搜索及任务列表请求，全部成功并核对授权公司。
- 本次 HTTP 样本：P50 34.3ms、P95 178.2ms、最大 211.0ms，总耗时约 270ms。
- 另有进程内 HTTP 注入的数据库基准，记录为 scale.json；网络测试单独记录为 scale-http.json，避免混用指标。

这些是单机短时查询样本，包含本机 Docker 网络，不包含公网、TLS、长时间稳定性或多人同时上传大文件的延迟；不能推导为生产 SLA。10 万条记录是索引占位数据，不是 10 万个真实附件。队列处理另通过真实任务和中断恢复测试验证。
