# 代账团队版操作手册

## 原版功能在哪里

登录后保留原版财务总览、专业模块、指标卡和四套主题。左侧仍可进入收入、往来、费用、资金、预算、资产、税务、发票、工资、对账、成本、报表、分析和投资；顶部仍有待办、异常、工作流、资料库和月结入口。团队交付与管理功能作为新增分组出现。

先在顶部选择客户公司和会计期间，再录入经营快照或处理待办。预算页面读取本期预算和支出，趋势读取同一公司的最近六期快照。不同公司、期间的数据分别保存；刷新或换浏览器后重新选择公司即可继续。主题、收藏、置顶按员工账号保存。

资料库保留上传、文件夹上传、搜索、类型及目录筛选、排序、引用、置顶和下载。上传前须建立本月工作单；在资料库“引用”所需原件版本，再打开原版工作流、填写任务要求，点击“创建执行记录并生成任务包”。也可以从月度工作单直接选择文件建立任务。只有原件可作为任务输入，已有成果需要由员工明确核对后另行作为资料上传。

发生网络错误或多人修改冲突时，页面会提示保存失败并保留草稿。先用提示旁的导出按钮保存草稿，再刷新核对服务器数据。已归档或待复核月份不能从原版页面绕过审批修改数据；月结勾选只是工作清单，不代表月度交付已经审批。

## 负责人首次设置

1. 用部署时生成的账号登录，修改初始密码，再重新登录。
2. 在“团队成员”创建员工。负责人可管理全部客户；复核、经办和只读人员必须另行分配公司。
3. 在“客户公司”新建公司，使用内部编号防止重复建档。点击“管理授权”，把公司分配给经办和复核人员。
4. 设置该公司后续月份的资料清单。已有工作单保留创建时的模板，不会随模板变更。
5. 在“月度交付”选择公司、会计期间、经办、复核和截止日期，创建工作单。经办和复核必须不同人。

批量建立使用当前公司列表中的客户，最多显示 100 家；可按搜索结果分批处理。接口允许一次提交至多 2000 家。系统不提供法定申报期限判断，截止日期由团队自行确认。

## 完成一个客户月份

### 收集与核对

上传流水、账务、票据等原件，并把清单项目关联到文件版本。同名上传保留旧版本。清单必需项未齐备，系统不能进入下一阶段；指定复核人员或负责人可说明理由豁免，但不能豁免自己经办的批次。

点击“资料齐备，进入核对”，核对后进入经办处理。PDF 和图片仅作为原件保存；系统没有自动 OCR、发票验真或税务结论。

### 在 WorkBuddy 处理

1. 进入本月工作单，在“WorkBuddy 任务交接”选择工作流和输入文件版本。
2. 建立执行记录，点击“生成 WorkBuddy 任务包”。后台任务完成后下载 ZIP。
3. 解压到该客户独立的工作目录。任务说明中包含工作流提示词、资料要求、输出要求和人工复核要求。只处理包内资料副本，不覆盖原件。
4. 在 WorkBuddy 处理，填写校验清单，保留异常及处理说明。自动化结果不能代替付款、记账、报税或重大判断的人工批准。
5. 回到原工作单，以“处理成果”上传文件。在对应执行记录粘贴任务包中的 `return-manifest.json`，填写校验说明后回传。
6. 输入文件变化或成果版本不一致时，重新建立任务记录。复制提示词、下载任务包均不表示处理完成。

回传校验核对任务归属、输入摘要和成果所属工作单；它不宣称理解或核实 AI 输出的会计正确性。经办仍须填写金额、行数和勾稽检查结果。

### 复核与交付

经办填写校验说明，确认通过，清空已处理的未解决事项，然后提交独立复核。未回传的当前任务会阻止提交。

复核人员在“审核中心”或月度列表打开任务，下载、检查具体成果版本，写明通过或退回原因。参与过经办、提交或成果处理的人不能自审；调岗、更换负责人不清除历史责任。

通过后，员工在原客户渠道完成交付。系统不会向客户自动发送消息。上传交付证据，登记交付方式，完成归档。系统记录时间及证据编号。

复核后更换成果会撤销当前审批并回到处理阶段。已归档批次不可继续上传；必须先申请重开，由另一名独立复核人员说明理由批准，再形成新版本并复核。旧成果、旧复核及交付记录始终保留。

## 标准表格导入

“资料导入”提供客户建档、资料清单、银行流水、账务明细、交付清单的 Excel 和 CSV 空模板。

| 模板 | 必填字段 | 用途 |
|---|---|---|
| 客户建档 | code、name | 建立客户公司；已有编号不重复建立 |
| 资料清单 | category、required | 调整所选公司未来月份模板；required 为 true/false |
| 银行流水 / 账务明细 | date、reference、amount | 期间内标准核对数据 |
| 交付清单 | period、file | 保存可追溯的导入记录，不自动变更审批状态 |

日期用 YYYY-MM-DD，期间用 YYYY-MM，金额为普通数字、最多两位小数。表格只接受 CSV/XLSX，每次最多 10MB、10000 行、100 列；先把公式转为数值，宏与外部链接不接受。

先选公司和期间，再选择文件。非标准列名可提供映射，例如 `{"amount":"金额","date":"日期","reference":"单号"}`。预览显示错误行、前几行数据和金额合计；有错误时不能确认。确认后在后台任务查看结果，重复确认不会重复导入。

银行核对输入已确认的流水与账务导入编号。同公司授权人员可以协作核对。日期、单号和金额全部一致且双方候选唯一时才自动匹配；重复候选和未匹配项由人处理。

## 员工变动与个人设置

- 停用员工或重置密码会立即撤销旧会话。撤销公司授权对既有会话和待执行任务同样生效。
- “账号设置”可改密并查看最近工作单；顶部“工作流”可收藏。个人偏好保存在账号下，公司业务以服务端为准。
- 遇到“记录已被修改”，刷新后核对同事改动，再重新提交；不要反复点击提交覆盖他人修改。
- 后台任务失败可查看原因并重试。负责人可在运行页面看到全机构的失败任务。
- 只读人员可查看记录和下载当前已复核成果，不能下载原始附件或导出任务包。

## 旧数据导入

只有负责人可操作。先明确选择目标公司，再上传原个人版 v2 JSON 备份，预览后确认。记录标为历史导入，不自动恢复审批、交付或文件；原始附件必须另行上传。原 WorkBuddy 本机数据保留。

## 日常检查

每天查看待补件、逾期、待复核及失败任务。负责人检查备份成功时间和可用存储空间；备份异常先修复，不以“页面能打开”代替恢复验证。首次试运行仅使用少量客户，确认数据、职责、期限和交付口径后再扩展。
