# 代账团队版操作手册

## 原版功能在哪里

登录后保留原版财务总览、专业模块、指标卡和四套主题。左侧仍可进入收入、往来、费用、资金、预算、资产、税务、发票、工资、对账、成本、报表、分析和投资；顶部仍有待办、异常、工作流、资料库和月结入口。团队交付与管理功能作为新增分组出现。

先在顶部选择客户公司和会计期间，再录入经营快照或处理待办。预算页面读取本期预算和支出，趋势读取同一公司的最近六期快照。不同公司、期间的数据分别保存；刷新或换浏览器后重新选择公司即可继续。主题、收藏、置顶按员工账号保存。

资料库保留上传、文件夹上传、搜索、类型及目录筛选、排序、引用、置顶和下载。上传前须建立本月工作单；在资料库“引用”所需原件版本，再打开原版工作流、填写任务要求，点击“创建执行记录并生成任务包”。也可以从月度工作单直接选择文件建立任务。只有原件可作为任务输入，已有成果需要由员工明确核对后另行作为资料上传。

发生网络错误或多人修改冲突时，页面会提示保存失败并保留草稿。先用提示旁的导出按钮保存草稿，再刷新核对服务器数据。已归档或待复核月份不能从原版页面绕过审批修改数据；月结勾选只是工作清单，不代表月度交付已经审批。

## 负责人首次设置

1. 用部署时生成的账号登录，修改初始密码，再重新登录。
2. 在“团队成员”创建员工。负责人可管理全部客户；复核、经办和只读人员必须另行分配公司。
3. 在“客户公司”点击“客户建档”，填写名称、内部编号、联系人和服务交接备注，选择默认经办与复核人员，并填写必需、可选资料要求。
4. 勾选“同时安排首月工作”，填写期间与截止日期。保存会一并完成建档、授权和首月任务；其中一步失败不会留下半套记录。内部编号防止重复建档，经办与复核必须不同人。
5. 保存后进入客户档案，点击“进入本月工作”即可收集资料。以后月份可在档案中填写截止日期，沿用默认分工和模板；重复安排会打开已有工作单。

客户清单可筛选“分工待完善”“本月未安排”。分工待完善包含默认人员未设置、停用、角色不适合或授权被撤销。旧客户不会自动推断默认经办，负责人需先确认。默认分工及资料要求只用于之后创建的月份；已有月份通过“分工与记录”明确交接，历史经办责任不会清除。

客户档案可查看最近 24 个月份和公司协作人员。负责人可增减公司授权，主管仍可修改后续月份资料要求。撤权立即生效，但不会静默替换工作单负责人；应先安排接手人员，并检查相关月份。多人同时修改客户档案时，后保存者会收到冲突提示，需重新打开最新档案。

点击“安排月度工作”后填写分工及期限。单个任务可直接选择客户；批量建立必须明确勾选客户，最多从已加载的 100 家中选择，可通过顶部搜索分批处理。接口允许一次提交至多 2000 家。系统不提供法定申报期限判断，截止日期由团队自行确认。

## 每天从交付工作台开始

月度交付首屏提供待补件、逾期、待复核、待交付等指标，点击即可进入对应清单。“我经办／我复核”按当前账号筛选；客户搜索、阶段和关注事项可组合使用。统计覆盖当前授权范围内的全部匹配工作，不只是当前页。

列表可同时查看经办、复核、资料进度、截止日期和下一步；阶段看板展示本页任务并支持翻页。看板不通过拖动更改审批状态。任务详情分为“资料收集、经办处理、复核与交付、分工与记录”，顶部说明当前阶段与下一步。

资料不齐时，可以“复制补件清单”，核对后自行发给客户。复核区展示本次送审文件版本及经办校验说明；工作单动态可查看交付方式与证据名称。界面会提示自审限制，最终权限和流程检查仍由服务器执行。

## 完成一个客户月份

### 收集与核对

工作单顶部支持批量上传，每批最多 30 个、合计 200 MB，单个 50 MB。选择文件用途后可逐项关联资料清单；每项独立显示结果，失败可重试，成功项不会重复保存。未上传队列在离开页面后不保留。“缺件跟进”可记录联系渠道、结果和下次跟进日期，补件后保留历史。

收集阶段可直接在缺件项目选择文件，点击“上传并关联”。文件保存和清单关联共同完成，不用再选一次原件；格式、版本或归属检查失败时不产生可用资料记录。也可继续关联已上传的原件。

上传流水、账务、票据等原件，并把清单项目关联到文件版本。同名上传保留旧版本。清单必需项未齐备，系统不能进入下一阶段；指定复核人员或负责人可说明理由豁免，但不能豁免自己经办的批次。

点击“资料齐备，进入核对”，核对后进入经办处理。PDF 和图片仅作为原件保存；系统没有自动 OCR、发票验真或税务结论。

### 在 WorkBuddy 处理

1. 进入本月工作单，在“WorkBuddy 任务交接”选择工作流和输入文件版本。
2. 点击“建立任务并生成任务包”，在当前工作单等待完成后直接下载 ZIP，失败可原地重试。
3. 解压到该客户独立的工作目录。任务说明中包含工作流提示词、资料要求、输出要求和人工复核要求。只处理包内资料副本，不覆盖原件。
4. 在 WorkBuddy 处理，填写校验清单，保留异常及处理说明。自动化结果不能代替付款、记账、报税或重大判断的人工批准。
5. 回到对应执行记录，在该任务内上传成果。读取或粘贴任务包中的 `return-manifest.json`，明确勾选本次任务的成果文件，填写校验说明后回传。工作单顶部的“人工处理成果”用于人工完成的文件，不用于给 WorkBuddy 任务补传成果。
6. 输入文件变化、复核退回或需要更正已回传成果时，在原任务的“修订或取消任务”中填写原因并建立修订任务；必要时重新选择输入。下载新的任务包，按新任务上传及回传。复制提示词、下载任务包均不表示处理完成。

回传校验核对任务归属、输入摘要和成果所属工作单；它不宣称理解或核实 AI 输出的会计正确性。经办仍须填写金额、行数和勾稽检查结果。

## 大量附件与成果归属

### 翻页查找和跨页选择

资料库及工作单附件每页默认显示 50 份。搜索、文件类型、目录和排序针对该公司本期的全部授权附件；总数不是当前页条数。置顶也作用于完整列表，末页的文件置顶后可以出现在第一页，个人置顶不会影响同事。

选择任务输入、回传成果或人工送审成果时，可以翻页、搜索和调整筛选继续勾选。“已选文件”保留明确的文件版本，不会因当前页没有该文件而取消。每次最多选择 100 份；超过时按业务目的拆分任务，或先整理成果再选择。同一执行的回传完成后，后续更正走修订任务。切换公司、期间或工作单后重新选择，不能沿用上一客户的选择。

遇到“附件或置顶顺序已变化”，刷新第一页再继续。原选择会保留供核对；若所选文件已经不是最新版本、任务已失效或权限发生变化，按提示移除并重新选择。不要把刷新列表当成已经更新了任务包里的输入版本。

历史记录中的文件仍可按固定版本查看；当前任务的输入只选可用的最新原件。只读账号不能下载原件或任务包，只能下载当前已经复核的成果。

### 任务成果与人工成果分别处理

| 文件来源                     | 上传位置                                           | 如何进入送审                                     |
| ---------------------------- | -------------------------------------------------- | ------------------------------------------------ |
| WorkBuddy 任务成果           | 对应执行记录内的成果上传区                         | 核对回传清单，明确选择该任务的成果并完成回传     |
| 人工完成的成果               | 工作单“人工处理成果”上传区                         | 在送审区明确选择最新人工成果，并填写人工校验说明 |
| 过程草稿或仅需留存的历史文件 | 留在资料记录中；历史待确认文件可选择“排除本次送审” | 不自动进入本次送审及交付包                       |

同名成果在不同 WorkBuddy 任务内各有自己的版本，人工成果也单独管理。不能把任务甲的成果用于任务乙回传。仅上传成功不表示已回传；人工成果也不会因上传时间较新而自动加入送审。

### 更正已回传成果、修订或取消任务

1. 打开原执行记录的“修订或取消任务”，填写真实原因。
2. 需要继续处理时选择“建立修订任务”。输入已经变化或任务失效时重新选择输入；输入未变时也可主动选择替换输入。
3. 下载修订任务的新包，在新任务内上传及回传成果。原任务、原回传清单和文件保留，不在旧回执上覆盖文件。
4. 已不再需要的任务选择“取消此任务”。取消保留原因及历史记录，其成果不再随当前任务进入送审；需要纳入的人工成果必须另行明确处理。

修订或取消影响已送审内容时，原审批失效，需要再次送审。失效但未修订或取消的当前任务会阻止送审。已归档月份必须先申请重开并由独立复核人员批准；更正后仍须重新复核，原交付记录保留。

### 升级后的历史成果待确认

尚未归档的旧月份可能出现“历史成果归属待确认”。负责人或本月经办逐份核对文件，明确属于某个 WorkBuddy 任务、人工处理成果，或选择“排除本次送审”，填写确认原因后保存。没有依据时不要按文件名或上传时间猜测任务。

若提示目标来源已有同名成果，不要强行把旧版本合并过去。核对后选择仅留档，或确认它实际属于哪个独立执行；确需更正当前任务时走修订。历史待确认项未处理完，系统不会继续送审、复核或交付。确认引起送审内容变化时同样需要重新复核。

已归档批次保留原成果、审批和交付记录，不要求为此次升级重新给历史文件分组。旧个人版 JSON 导入仍只是历史记录，不能充当新系统的审批证据。

分页及归属规则的测试范围见 [本轮验收报告](ATTACHMENT-OWNERSHIP-ACCEPTANCE.md)；报告中标为待补充的界面项目不能视作已通过。

## 复核与交付

“经办处理”页显示送审前检查：成果文件、外部任务回传、当前版本和复核人员资格。缺项先补齐，再填写人工校验说明。若复核人员被撤权或参与过本批次经办，需要先调整分工。

审核中心有“我可复核、全部待复核、退回跟进、待交付、重开申请”五个队列，显示送审人、文件版本、校验摘要、退回或重开理由。“我可复核”排除本人经办、本人提交和非指定复核的批次；负责人也不能自审。进入工作单处理后可返回原队列继续下一家，不提供跳过版本检查的批量审批。

经办填写校验说明，确认通过，清空已处理的未解决事项，然后提交独立复核。未回传的当前任务会阻止提交。

复核人员在“审核中心”或月度列表打开任务，下载、检查具体成果版本，写明通过或退回原因。参与过经办、提交或成果处理的人不能自审；调岗、更换负责人不清除历史责任。

通过后，员工在原客户渠道完成交付。系统不会向客户自动发送消息。上传交付证据，登记交付方式，完成归档。系统记录时间及证据编号。

复核后更换成果会撤销当前审批并回到处理阶段。已归档批次不可继续上传；必须先申请重开，由另一名独立复核人员说明理由批准，再形成新版本并复核。旧成果、旧复核及交付记录始终保留。

## 标准表格导入

“资料导入”提供客户建档、资料清单、银行流水、账务明细、交付清单的 Excel 和 CSV 空模板。

| 模板                | 必填字段                | 用途                                             |
| ------------------- | ----------------------- | ------------------------------------------------ |
| 客户建档            | code、name              | 建立客户公司；已有编号不重复建立                 |
| 资料清单            | category、required      | 调整所选公司未来月份模板；required 为 true/false |
| 银行流水 / 账务明细 | date、reference、amount | 期间内标准核对数据                               |
| 交付清单            | period、file            | 保存可追溯的导入记录，不自动变更审批状态         |

日期用 YYYY-MM-DD，期间用 YYYY-MM，金额为普通数字、最多两位小数。表格只接受 CSV/XLSX，每次最多 10MB、10000 行、100 列；先把公式转为数值，宏与外部链接不接受。

先选公司和期间，再选择文件。非标准列名可提供映射，例如 `{"amount":"金额","date":"日期","reference":"单号"}`。预览显示错误行、前几行数据和金额合计；有错误时不能确认。确认后在后台任务查看结果，重复确认不会重复导入。

银行核对输入已确认的流水与账务导入编号。同公司授权人员可以协作核对。日期、单号和金额全部一致且双方候选唯一时才自动匹配；重复候选和未匹配项由人处理。

## 员工变动与个人设置

- 停用员工或重置密码会立即撤销旧会话。撤销公司授权对既有会话和待执行任务同样生效。
- “账号设置”可改密并查看最近工作单；顶部“工作流”可收藏。个人偏好保存在账号下，公司业务以服务端为准。
- 遇到“记录已被修改”，刷新后核对同事改动，再重新提交；不要反复点击提交覆盖他人修改。
- 后台任务失败可查看原因并重试。负责人可在运行页面看到全机构的失败任务。
- 只读人员可查看记录和下载当前已复核成果，不能下载原始附件或导出任务包。

## 旧数据导入

只有负责人可操作。先明确选择目标公司，再上传原个人版 v2 JSON 备份，预览后确认。记录标为历史导入，不自动恢复审批、交付或文件；原始附件必须另行上传。原 WorkBuddy 本机数据保留。

## 日常检查

每天查看待补件、逾期、待复核及失败任务。负责人检查备份成功时间和可用存储空间；备份异常先修复，不以“页面能打开”代替恢复验证。首次试运行仅使用少量客户，确认数据、职责、期限和交付口径后再扩展。

## 人员交接与账号调整

团队成员页显示授权客户和在办月份工作量。选择员工、客户和接手人，预览默认分工及未归档月份，填写原因后统一转交；可明确选择撤销原员工的客户权限。已归档分工及历史经办责任保留，不能转交给不独立的复核人员。仍有不兼容职责的员工不能直接停用或降级，应先交接。账号变更会撤销旧会话。
